# Слой — screenshot tester

Локальный инструмент ручного совмещения макета и реализации. React + TypeScript + Vite. Без AI, облачной обработки, внешних шрифтов и отправки изображений на сервер. Демо генерируется браузером и не содержит пользовательских данных.

## Запуск

Требуется Node.js 22.12+ (проверено на Node 26).

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:4173 . Для production-сборки: `npm run build`; результат — `dist/`. Нельзя открывать исходный index.html напрямую через file://.

## Работа

1. Загрузите эталон и реализацию: PNG/JPG/WebP, до 20 МБ, до 4096 px по стороне и 4 млн пикселей.
2. Смещайте реализацию через X/Y или перетаскиванием холста. На сфокусированном холсте стрелки двигают на 1 px, Shift + стрелки — на 10 px. Масштаб равномерный; изображения автоматически не растягиваются.
3. Наложение использует указанную непрозрачность, шторка показывает реализацию слева и эталон справа, различия выделяются розовым.
4. PNG diff экспортирует карту различий, JSON — размеры, трансформацию, порог и статистику. Сброс возвращает X/Y=0, масштаб=100%.

## Что считается различием

Пиксель изменён, если максимальная абсолютная разница каналов RGBA строго больше порога (0–255). Непокрытые реализацией пиксели эталона всегда считаются изменёнными, даже прозрачные. Процент вычисляется по всей площади эталона. Содержимое реализации вне границ эталона **не учитывается**. Это сырая пиксельная метрика, не оценка качества дизайна; сглаживание, прозрачность и цветовые профили браузера влияют на результат. Масштабирование использует стандартную интерполяцию Canvas.

## Ограничения стартовой версии

Только ручное выравнивание, без якорей, автоматического поиска, сохранения сессий и пакетных проверок. Статистика пересчитывается в основном потоке; большие изображения могут тормозить. Размер проверяется после декодирования браузером: не открывайте недоверенные файлы с гигантскими заявленными размерами. Полностью прозрачные RGB могут нормализоваться Canvas. Animated WebP не предназначен для воспроизводимого сравнения. После перезагрузки файлы нужно выбрать снова.

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Для уже установленного Chromium можно указать `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome npm run test:e2e`. E2E проверяют демо, JSON/PNG-экспорт, загрузку, ошибки, drag, клавиатуру и отсутствие горизонтального переполнения на 390 px. Тестовые изображения генерируются локально. `test-results/`, `node_modules/`, `dist/` исключены из Git. Не добавляйте пользовательские скриншоты и отчёты в репозиторий.
